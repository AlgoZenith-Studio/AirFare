# dashboard/frontend

Next.js 18+ sovereign analyst web portal. TypeScript, Tailwind CSS (bound to `packages/design-tokens`), Framer Motion, Firebase Auth SDK.
Role-gated portal (VIEWER, ANALYST, ADMIN) for econometric price index drill-down, waterfall attribution, and cryptographic auditability.

Runs fully decoupled from the backend via NEXT_PUBLIC_USE_MOCK=true, seeded from data/seed.

See TRD.md Part C for design tokens and the seven non-negotiable frontend rules.
